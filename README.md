 Project Overview

This project is a fully responsive Personal Portfolio Website designed to showcase professional information, skills, achievements, education, and projects in a clean and modern layout. The website was built using only HTML, CSS, and JavaScript, without any external frameworks, ensuring complete control over the design and responsiveness.

The primary goal of this project is to provide a visually appealing and user-friendly interface that highlights an individual’s career journey and skills, making it suitable for recruiters, HR teams, and potential clients.

Key Features
1. Responsive Navigation Bar

A minimal top navigation bar with links to all major sections.

Sticky behavior and smooth scrolling.

2. Hero Section

Includes a professional profile photo, name, and short introduction.

Designed with a two-column layout for perfect alignment on all screens.

3. About Me Section

Contains a clean card layout with personal details.

Highlights professional background, career goals, and technical strengths.

4. Education Section

Displays all academic qualifications in structured cards.

Includes course name, institution, and completion year.

5. Skills Section

Categorized skills such as HTML, CSS, JavaScript, Java, UI Design, and more.

Implemented using pill-style UI for a neat visual feel.

6. Projects Section

Showcases past work with proper titles, descriptions, and project dates.

Ideal for demonstrating real-world experience.

7. Smooth Animations

Fade-in effects triggered while scrolling.

Enhances the site's professional look and user engagement.

8. Footer

Simple footer with copyright information.

 Objectives Achieved

Built a complete front-end website without any frameworks.

Implemented fully responsive layout for mobile, tablet, and desktop.

Designed a clean UI focusing on readability and modern aesthetics.

Added subtle animations with JavaScript Intersection Observer.

Structured the project following industry-level HTML & CSS practices.

 Outcome

This portfolio website serves as a professional online identity, helping to present personal achievements, skills, and project experience in an organized and impactful manner. It is suitable for job applications, interviews, and client presentations.
